# AI Coding Agent Quickstart

This page is the fastest entrypoint into the repository's knowledge base when you are an AI coding agent trying to answer a question, review a change, or edit documentation about zero-knowledge systems.

## How to Work Efficiently

1. Start with the smallest document that matches the task.
2. Use the glossary when a term is unfamiliar rather than scanning the whole manuscript.
3. Follow each document's **Related Topics** links to expand only when the task requires more context.
4. Use the bibliography when you need to trace a claim back to cited literature.
